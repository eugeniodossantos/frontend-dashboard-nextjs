# Frontend Analytics Dashboard

Projeto de portfólio desenvolvido para demonstrar competências de **Frontend Development** com **Next.js, React, TypeScript, UI responsiva e consumo de API REST**.

## Funcionalidades

- Dashboard responsivo para desktop, tablet e mobile
- Consumo de API REST pública
- Estados de loading e erro
- Pesquisa em tempo real por nome, email ou empresa
- Cards de métricas
- Tabela responsiva de utilizadores
- Interface profissional com foco em UX

## Tecnologias

- Next.js
- React
- TypeScript
- CSS responsivo
- Fetch API
- JSONPlaceholder REST API

## Executar localmente

```bash
npm install
npm run dev
```

Depois abre `http://localhost:3000`.

## Objetivo

Este projeto foi criado como demonstração técnica de competências em frontend, incluindo organização de componentes, tipagem, gestão de estados, consumo de APIs e construção de interfaces adaptáveis.
